# Push Notifications Setup for PWA

## Overview

This guide walks you through setting up Web Push Notifications for your Police Department Scheduler PWA using VAPID (Voluntary Application Server Identification).

## Step 1: Generate VAPID Keys

First, install the web-push utility globally:

```bash
npm install -g web-push
```

Generate your VAPID key pair:

```bash
web-push generate-vapid-keys
```

You'll get output like:
```
Public Key: BEx...
Private Key: xyz...
```

Save these keys securely!

## Step 2: Set Environment Variables

### Local Development (.env.local)

Add to your `.env.local` file:

```env
VITE_VAPID_PUBLIC_KEY=<your-public-key-here>
```

### GitHub Secrets (for CI/CD)

1. Go to your GitHub repository
2. Settings → Secrets and variables → Actions
3. Add new secrets:
   - **VITE_VAPID_PUBLIC_KEY**: Your public VAPID key
   - **VAPID_PRIVATE_KEY**: Your private VAPID key (for Edge Function)
   - **VAPID_PUBLIC_KEY**: Same as public key (for Edge Function)

### Supabase Edge Function Secrets

1. Go to your Supabase project dashboard
2. Edge Functions → select `send-push-notification`
3. Add secrets:
   - **VAPID_PRIVATE_KEY**: Your private VAPID key
   - **VAPID_PUBLIC_KEY**: Your public VAPID key

## Step 3: Update Deployment Workflow

Edit `.github/workflows/deploy.yml`:

```yaml
- name: Build site
  run: npm run build
  env:
    VITE_SUPABASE_URL: ${{ secrets.VITE_SUPABASE_URL }}
    VITE_SUPABASE_ANON_KEY: ${{ secrets.VITE_SUPABASE_ANON_KEY }}
    VITE_VAPID_PUBLIC_KEY: ${{ secrets.VITE_VAPID_PUBLIC_KEY }}  # ADD THIS
    VITE_APP_URL: ${{ steps.env-vars.outputs.APP_URL }}
    NODE_ENV: production
```

## Step 4: Database Setup

Ensure your Supabase database has the required table:

```sql
CREATE TABLE user_push_subscriptions (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  user_id UUID NOT NULL REFERENCES profiles(id) ON DELETE CASCADE,
  subscription JSONB NOT NULL,
  enabled BOOLEAN DEFAULT true,
  created_at TIMESTAMP DEFAULT now(),
  updated_at TIMESTAMP DEFAULT now(),
  UNIQUE(user_id)
);

CREATE INDEX idx_user_push_subscriptions_user_id ON user_push_subscriptions(user_id);
CREATE INDEX idx_user_push_subscriptions_enabled ON user_push_subscriptions(enabled);
```

## Step 5: Deploy Edge Function

Deploy the push notification function to Supabase:

```bash
supabase functions deploy send-push-notification
```

Or through the Supabase dashboard:
1. Edge Functions → Create new function → `send-push-notification`
2. Copy the code from `supabase/functions/send-push-notification/index.ts`

## Step 6: Test Locally

1. Start your dev server:
   ```bash
   npm run dev
   ```

2. Open the app and log in

3. Look for the notification banner "Police Department Notifications"

4. Click "Enable Notifications" and grant browser permission

5. In the dev panel (bottom right if DEV mode is on), click "Test Push Notification"

## Usage in Your App

### Request Notification Permission

```typescript
import { registerForPushNotifications } from '@/utils/pushNotifications';

// When user clicks enable
const permission = await Notification.requestPermission();
if (permission === 'granted') {
  await registerForPushNotifications(userId, serviceWorkerRegistration);
}
```

### Send Push Notifications

```typescript
import { sendPushNotification } from '@/utils/pushNotifications';

// Send to specific officers
await sendPushNotification(
  ['user-id-1', 'user-id-2'],
  'Shift Change Alert',
  'Your shift on 10/15 has been changed from Day to Night',
  {
    tag: 'shift-change',
    data: {
      type: 'SHIFT_CHANGE',
      shiftDate: '2026-10-15',
      newShift: 'Night'
    }
  }
);

// Send to supervisors about PTO request
await sendPushNotification(
  supervisorIds,
  'New PTO Request',
  'Officer John Smith requested time off',
  {
    tag: 'pto-request',
    data: {
      type: 'PTO_REQUEST',
      requestId: request.id
    }
  }
);
```

### Service Worker Handles Notifications

The service worker (generated by Vite PWA) will:
- Display notifications to users
- Handle notification clicks
- Manage notification lifecycle

## Security Considerations

1. **VAPID Keys**: Keep your private key secure - never commit to git
2. **Subscriptions**: Stored encrypted in Supabase
3. **Edge Function**: Requires Supabase authentication
4. **HTTPS Only**: Push only works over HTTPS (automatic on GitHub Pages)

## Troubleshooting

### "VAPID keys not configured"
- Check `.env.local` has `VITE_VAPID_PUBLIC_KEY`
- Verify environment variable is set in build

### "Push notifications not supported"
- Check browser supports Push API (Chrome, Firefox, Edge)
- Verify HTTPS connection
- Check service worker is registered

### Subscriptions not saving
- Verify `user_push_subscriptions` table exists
- Check user has permission to insert rows
- Look at browser console for errors

### Push not reaching users
- Verify `send-push-notification` Edge Function is deployed
- Check VAPID keys are correct
- Verify subscriptions are marked `enabled: true`
- Check browser DevTools → Application → Service Workers → Push events

The push notification system integrates with:
- **PTO Requests**: Notify supervisors of new requests
- **Shift Changes**: Alert officers of schedule updates
- **Vacancy Alerts**: Notify supervisors of open shifts
- **Emergency Alerts**: Broadcast to all officers
- **Anniversary Reminders**: Background notification checks
